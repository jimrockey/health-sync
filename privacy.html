Privacy policy

Last updated: November 24, 2026

Health Sync is a personal tool used only by its owner, to read the owner's own health data.

What it accesses

With the owner's consent, it uses read-only Google Health API scopes for activity and fitness, sleep, and health metrics and measurements (for example steps, heart rate, sleep stages and blood oxygen).

How the data is used

The data is saved only to a local database on the owner's own computer and is used only to show the owner their own trends. It is not sold or shared with anyone, not used for advertising, and not used to train AI or machine-learning models. It does not leave the owner's computer except when the owner chooses to do something with it.

Google API Services User Data Policy

Health Sync's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The owner can delete the local database at any time.

Contact

Questions: open an issue on GitHub.
